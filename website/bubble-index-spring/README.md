# bubble-index-spring

The current Spring Boot web application that serves [thebubbleindex.com](https://www.thebubbleindex.com). It reads the D3 data files generated by the post-processing utilities and exposes them through a set of web endpoints rendered with Groovy templates.

## Prerequisites

| Requirement | Version |
|---|---|
| Java JDK | 8 |
| Apache Maven | 3.6+ |

## Building

```bash
mvn clean package
```

## Running

```bash
java -jar target/bubble-index-spring-*.war
```

Or deploy the generated WAR to an external Tomcat server.

## Stack

- [Spring Boot 2.0](https://spring.io/projects/spring-boot) with Groovy templates
- [H2](https://www.h2database.com/) in-memory database
- Spring Data JPA
- Jakarta JSON-B (`yasson` / `javax.json`)
