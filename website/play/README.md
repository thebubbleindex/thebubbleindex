# play

A legacy [Play Framework](https://www.playframework.com/) (version 1.x) web application for The Bubble Index website. This project is kept for historical reference and is **not actively maintained**. The current web application is in [bubble-index-spring](../bubble-index-spring/).

## Structure

```
play/
├── app/         # Controllers, models, and views (Groovy/Java)
├── conf/        # Application configuration, routes, and dependencies
├── lib/         # Bundled JAR dependencies
├── public/      # Static assets (CSS, JavaScript, images)
└── test/        # Application tests
```

- [bubble-index-spring](../bubble-index-spring/) — the current Spring Boot replacement for this application
