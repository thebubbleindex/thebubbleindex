# original-standalone

A legacy version of The Bubble Index application, originally built with Apache NetBeans. This project is kept for historical reference and is **not actively maintained**.

For the current, actively maintained version of the application see [../thebubbleindex-standalone](../thebubbleindex-standalone/).

## Notes

- Built with Apache NetBeans project tooling (`build.xml` / Ant).
- Source code in `src/` represents the state of the application before it was migrated to the Maven-based build in `thebubbleindex-standalone`.
- The `lib/` directory contains the third-party JARs that were bundled with the NetBeans project.
